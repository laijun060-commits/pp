[RAIJUN ZOO 포트폴리오 영상 관리 가이드]

1. 제작한 포트폴리오 영상 파일(.mp4)을 이 movie 폴더에 모아 보관하세요.
2. YouTube 채널(https://www.youtube.com/@raijunzoo)에 영상을 '일부 공개' 또는 '공개'로 업로드하세요.
3. 프로젝트 루트의 js/portfolio-data.js 파일에서 해당 프로젝트 항목의:
   - youtubeId: "유튜브_영상_ID" (예: https://youtu.be/ABC12345 에서 ABC12345)
   - 또는 localVideo: "movie/영상파일명.mp4"
   을 입력하면, 포트폴리오 카드 클릭 시 럭셔리 시네마 모달에서 바로 영상이 재생됩니다!
